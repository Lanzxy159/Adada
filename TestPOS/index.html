About MockStore

Welcome to MockStore — a demo e-commerce website built for learning and development purposes. This is a mock website, and all products displayed are for demonstration only.

Our goal is to simulate a real online shopping experience, where users can browse products, view details, and interact with a modern web application.

Note: The "Buy Now" button is part of a prototype system and does not process real transactions.

This project showcases a full-stack setup using a frontend interface, a backend API, and a database to manage product data dynamically.
